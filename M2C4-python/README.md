## Ejercicios

### Ejercicio 1
Crea una lista, una tupla, un float, un entero, un decimal y un diccionario.

### Ejercicio 2
Redondea tu float hacia arriba.

### Ejercicio 3
Obtén la raíz cuadrada de tu float.

### Ejercicio 4
Selecciona el primer elemento de tu diccionario.

### Ejercicio 5
Selecciona el segundo elemento de tu tupla.

### Ejercicio 6
Añade un elemento al final de tu lista.

### Ejercicio 7
Reemplaza el primer elemento de tu lista.

### Ejercicio 8
Ordena tu lista alfabéticamente.

### Ejercicio 9
Usa reasignación para añadir un elemento a tu tupla.
