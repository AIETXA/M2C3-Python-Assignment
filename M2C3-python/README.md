## Conceptos incluidos

### Ejercicio 1
Crea una cadena de texto, un número, una lista y un booleano, cada uno almacenado en su propia variable.

### Ejercicio 2
Usa un índice para obtener las primeras 3 letras de tu cadena de texto y almacénalas en una variable.

### Ejercicio 3
Usa un índice para obtener el primer elemento de tu lista.

### Ejercicio 4
Crea una nueva variable numérica que sume 10 a tu número original.

### Ejercicio 5
Usa un índice para obtener el último elemento de tu lista.

### Ejercicio 6
Usa `split` para transformar la siguiente cadena en una lista:

```python
names = 'harry,alex,susie,jared,gail,conner'
```

### Ejercicio 7
Obtén la primera palabra de tu cadena usando índices. Usa la función `upper` para transformar las letras a mayúsculas. Crea una nueva cadena que combine la palabra en mayúsculas con el resto de la cadena original.

### Ejercicio 8
Usa interpolación de cadenas para imprimir una oración que contenga tu variable numérica.

### Ejercicio 9
Imprime `"hello world"`.
